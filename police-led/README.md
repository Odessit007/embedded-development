Програма імітує поліцейську мігалку.

Два рази блимає блакитний колір, потім 2 рази червоний.

Один крок циклу виглядає так:
* блим синім
* пауза
* блим синім
* пауза
* блим червоним
* пауза
* блим червоним
* пауза

Пауза між миготінням спочатку встановлюється у 1000 мс і поступово збільшується по 100 мс після кожного кроку циклу.

По досягнанні 200 мс пауза починає зростати до 1000 мс, після чого знову зменшуватись.

Відповідно маємо постійну зміну швидкості миготіння.
