Програма імітує поліцейську мігалку.

Два рази блимає блакитний колір, потім 2 рази червоний.

Один крок циклу виглядає так:
* блим синім
* пауза
* блим синім
* пауза
* блим червоним
* пауза
* блим червоним
* пауза

Пауза між миготінням спочатку встановлюється у 1000 мс і поступово зменшується на 200 мс після кожного кроку циклу.

По досягнанні 200 мс пауза починає зростати на 200 мс за крок, поки не дійде до 1000 мс, після чого знову зменшується.

Відповідно маємо постійну зміну швидкості миготіння.
