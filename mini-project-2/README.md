Реалізація світлофора з кнопкою аварійного режиму.

При першому натисканні на кнопку світлофор переходить з будь-якого режиму у режим миготіння жвотого. При другому натисканні переходить у режим постійного зеленого і продовжує далі по циклу (миготіння зеленого, постійний жовтий і т.д.).

Дебаунсінг кнопки реалізований як машина станів, скопійована з модуля 2-4. Код винесений в окрему бібліотеку для компактності.

Перемиканная режимів світлофора також реалізовано як машину станів.
1) Спочатку перевіряється зміна стану кнопки і якщо вона перейшла з ненатиснутого стану в натиснутий, то система переходить в стан миготіння жовтого.
2) В іншому випадку машина вимріює скільки часу пройшло з останньої зміни основних станів і послідовно перемикає стани по циклу: зелений постіний - зелений миготливий - жовтий - червоний - червоний та жовтий - зелений постійний. Зміна стану відбувається, якщо часу з останньої зміни пройшло більше ніж заданий поріг (наприклад, 5 секунд для постійного зеленого: якщо пройшло більше, то переходим в режим миготливого зеленого і т.д.).
3) Для обробки блимання використовується окрема зміна-трекер часу. Її значення порівнюється з поточним часом, щоб визначити чи треба змінити стан (горить - не горить).
