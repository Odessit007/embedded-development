Відео роботи: https://youtu.be/QjXRHAvAqEA?si=HjP-cbyza1bd2oTW


# Аварійний режим
При першому натисканні на кнопку світлофор переходить з будь-якого режиму у режим миготіння жовтого. При другому натисканні переходить у режим постійного зеленого і продовжує далі по циклу (миготіння зеленого, постійний жовтий і т.д.).

# Загальна логіка роботи
Перемиканная режимів світлофора також реалізовано як машину станів.
1) Спочатку перевіряється зміна стану кнопки і якщо вона перейшла з ненатиснутого стану в натиснутий, то світлофор переходить з поточного стану в стан миготіння жовтого, або переходить зі стану миготіння жовтого, якщо він вже в ньому, до стану постійного зеленого.
2) В іншому випадку машина вимріює скільки часу пройшло з останньої зміни регулярних станів і послідовно перемикає стани по циклу: зелений постіний - зелений миготливий - жовтий - червоний - червоний та жовтий - зелений постійний. Зміна стану відбувається, якщо з останньої зміни пройшло більше часу ніж заданий поріг (наприклад, 5 секунд для постійного зеленого: якщо пройшло більше, то переходимо в режим миготливого зеленого і т.д.).
3) Для обробки блимання використовується окрема змінна-трекер часу. Її значення порівнюється з поточним часом, щоб визначити чи треба змінити стан (горить - не горить).

# Структура коду
Основний файл main.cpp лише задає параметри для машини станів світлофора, ініціює машину і в loop() постійно оновлює стан. Код винесений в бібліотеку lib/trafficLightFSM.

Безпосередній контроль над лампочками виконується через клас Led (бібліотека lib/led).

Дебаунсінг кнопки реалізований як машина станів, скопійована з модуля 2-4 (бібліотека lib/buttonFSM).
