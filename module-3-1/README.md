### Опис реалізації
Код здебільшого скопійований з прикладу на ESP-IDF, який був на уроці.

Додано:
1) Два пороги гістерезису (підібрані так, щоб можна було "вимкнути" світло пальцем, тобто достатньо високі значення вольтажу: 2200 - це порог для "темряви", 2800 - порог для "світла").
2) Просте ковзне середнє (SMA) по 5 значенням. Перші 4 зчитування LDR ігноруються (тобто LED вимкнений), з 5-го значення і далі рішення про ввімкнення/вимкнення LED приймається на основі середнього арфиметичного останніх 5-ти зчитувань. SMA реалізовано на основі циклічного буферу, в якому зберігаються всі останні значення.

### Схема підключення
3V3 -- LDR -- GPIO 4
GPIO 4 -- 10k resistor -- GND
GPIO 16 -- 220 Ohm resistor -- LED -- GND

Тут мені трохи допоміг AI:
* In light: the LDR resistance is low, so GPIO4 is pulled closer to 3V3.
* In dark: the LDR resistance is high, so GPIO4 is pulled closer to GND.
